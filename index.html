What is Web Hosting?

Web hosting is a service that stores your website files on a server that is always online, so anyone can open your site using its address. Common types are shared hosting, VPS hosting, cloud hosting and static hosting such as GitHub Pages.

What is CI/CD?

CI/CD stands for Continuous Integration and Continuous Deployment. It means every code change is automatically tested and then published, without uploading files by hand.

  • Continuous Integration: code is merged, built and tested on every push.
  • Continuous Deployment: code that passes the tests goes live automatically.
